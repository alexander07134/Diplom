# Автотесты для мобильного приложения «Мобильный хоспис»

Данный репозиторий содержит проект автоматизации UI-тестирования мобильного приложения «Мобильный хоспис» с использованием фреймворка **Espresso**, языка **Java** и формирования отчетов через **Allure**.

## 🛠 Требования для запуска
Перед запуском тестов убедитесь, что у вас установлено следующее:
* **Android Studio** (актуальная версия).
* **JDK 17** (настроен в проекте).
* **Эмулятор Android** (рекомендуется Pixel 6 с версией API 36 / Android 16).
* **Node.js и npm** (для установки и запуска Allure).

## 🚀 Процедура запуска авто-тестов

### 1. Подготовка проекта
1. Склонируйте репозиторий на локальную машину.
2. Откройте папку проекта в Android Studio.
3. Дождитесь окончания синхронизации Gradle (Sync Project with Gradle Files).
4. В файле `gradle.properties` (в корне проекта) должна быть строка:
   `android.injected.androidTest.leaveApksInstalledAfterRun=true`

### 2. Запуск эмулятора
1. Откройте **Device Manager** в Android Studio.
2. Запустите эмулятор (например, Pixel 6 API 36).
3. Дождитесь полной загрузки ОС эмулятора.

### 3. Запуск тестов
**Способ А. Через интерфейс Android Studio:**
1. В левой панели Project разверните: `app -> src -> androidTest -> java -> ru.edu.qamid.tests`.
2. Нажмите правой кнопкой мыши на нужный класс (например, `AuthTests` или `NewsTests`) или на всю папку `tests`.
3. Выберите **Run 'Tests in ru.edu.qamid.tests'**.
